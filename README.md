# الزمالك.. حكاية وطن أبيض · ZAMALEK SC — THE WHITE CASTLE STORY

**كتاب مرجعي رقمي موثّق في تاريخ نادي الزمالك 1911–2026 · موقع ثابت جاهز للرفع على GitHub Pages**

A documented digital reference book on the history of Zamalek SC (1911–2026) — a static site ready to upload to GitHub Pages.

---

| القسم | الوصف |
|---|---|
| **الغلاف** | شعار النادي بشكل مميز + الهوية البيضاء الحمراء + التبديل بين العربية والإنجليزية |
| **المقدمة والمنهجية** | قواعد التوثيق الأربع + التصحيحات الموثقة علنًا |

## 🚀 كيف ترفعه على GitHub (خطوة بخطوة)

1. **أنشئ مستودعًا جديدًا** على [github.com/new](https://github.com/new)
   - الاسم المقترح: `Zamalek1` أو `Zamalek-Book`
   - اختر **Public** (لازم لـ GitHub Pages المجانية)
2. **ارفع محتويات هذا المجلد** (وليس المجلد نفسه — أي `index.html` يجب أن يقع في جذر المستودع مباشرة):
   - من صفحة المستودع: **Add file → Upload files** واسحب كل الملفات والمجلدات (`index.html`, `css/`, `js/`, `assets/`)
3. **فعّل GitHub Pages**:
   - Settings → Pages → **Source: Deploy from a branch** → Branch: **main** → Folder: **/(root)** → Save
4. بعد دقيقة إلى دقيقتين، موقعك يعمل على:
   `https://<اسم-حسابك>.github.io/<اسم-المستودع>/`
5. لتحديث أي محتوى لاحقًا: عدّل ملفات `js/*.js` وارفعها من جديد — Pages يتحدث تلقائيًا.

**معاينة محلية قبل الرفع:**
```bash
cd zamalek-white-castle-story
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```
(لا تفتح `index.html` بنقرة مزدوجة عبر `file://` فقط — بعض المتصفحات تحجب تحميل الصور النسبية؛ استخدم خادمًا محليًا.)

## 🖼️ الصور والشعار — المصادر والتراخيص

- الصور التاريخية **حقيقية وموثقة** من [ويكيميديا كومنز](https://commons.wikimedia.org/wiki/Category:Zamalek_SC) بتراخيصها الحرة (PD / CC BY / CC BY-SA). مصدر كل صورة وترخيصها في `assets/photos/credits.json`.
- **الشعار الرسمي** علامة تجارية لنادي الزمالك، وُضِع هنا في سياق توثيقي تعليمي غير تجاري — وإن أراد النادي حذفه فامسح ملفه واستبدل مراجع `crestSrc()` في `js/main.js`.
- ملف `js/photos-manifest.js` يُولَّد من الملفات الموجودة فعليًا: أي صورة مفقودة تختار منطقة عرض أنيقة تلقائيًا بدل صورة مكسورة — ويكفي أن تضيف الملف إلى `assets/photos/` وتعيد توليد الملف ليظهر.
- لاستكمال الأرشيف لاحقًا: أضف صورًا جديدة إلى `assets/photos/` ثم أدرج اسم الملف في `js/timeline.js` (خاصية `photo`) أو `js/legends.js` (خاصية `photo`) أو `js/sections.js` (`SECTION_PHOTOS`).

## 🔎 قائمة التصحيحات الموثقة (شفافية الكتاب)

كما وردت في فصل المنهجية وقسم المراجع داخل الموقع:

1. **حسن شحاتة**: جائزة 1970 هي **أفضل لاعب في آسيا** (وهو في الكويت) لا أفضل لاعب أفريقي؛ ومعها ثالث أفضل لاعب أفريقي 1974 وأفضل لاعب في أمم أفريقيا 1974.
2. **ميتم أوكبا**: الانتقال وافتتاح الملعب والمبنى الاجتماعي موثقان بعام **1959** في رئاسة أبو رجيلة — لا 1958.
3. **حلمي زامورا**: فترتا رئاسة (حتى يوليو 1971 ثم 1973–1984) = نحو **15 عامًا**، لا أكثر من 30.
4. **فينجادا**: لقب الدوري 2003–04 ثابت؛ وصف «موسم بلا هزيمة» **لا سند له** — استُبدل بـ«موسم بأربعة ألقاب موثقة».
5. **جيسوالدو فيريرا**: ثنائية 2014–15 ثابتة؛ أما 2022 فهو **لقبان في صيف واحد** (نهائي كأس 2020–21 في يوليو ثم دوري 2021–22 في أغسطس) وليس «ثنائية موسم 2021–22».
6. **مؤسس النادي**: المصادر الحديثة تصعد **جورج مرزباخ** (1911–1915)، ووثيقة 1912 تشير إلى **أنطوان بيانكي** رئيسًا — الخلاف موثق ولا يُحسم بالتخمين.
7. **عبد الرحمن فوزي**: انتقل من المصري إلى المختلط **صيف 1934 بعد المونديال** مباشرة.
